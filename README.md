# Volt

Volt is a buffer-based networking package for Roblox: an IDL compiler written in Luau that generates plain Luau client and server modules, plus a small runtime. It is being built from scratch with Blink and Zap as source references, and a framework wrapper that replaces Knit will sit on top of it.

- `KB/` is the project knowledge base, an Obsidian vault. Start at `KB/Core.md`.
- `Reference/` (gitignored) holds read-only snapshots of third-party source kept locally for design reference; see `KB/Research/reference-source-snapshots.md` for how to re-fetch it.
- `.claude/` holds the Claude Code hooks that enforce the KB workflow.
