# The project is named Volt
Up: [[Decisions]]

**Decision:** Mike named the project **Volt** on 2026-09-20, choosing it from three one-word candidates offered: Volt, Pulse, Relay. The candidates were picked to avoid the taken names Blink, Zap, ByteNet, Warp, Packet, Comm, Red, Signal, and the Roblox class name Beam. The repository folder and GitHub remote (`Fadeluc-123/Volt`) carry the name.

**Alternatives:** Pulse and Relay remain the fallbacks if Volt collides.

**Revisit when:** a collision is found. The name has **not yet been verified** against Wally, pesde, the DevForum and GitHub for an existing Roblox library; that check is a deliverable in [[Planning/volt-next-session-deliverables]].

**Consequences:** Generated remote names, the Wally or pesde package name and the CLI binary name all derive from "Volt" once the check passes.
