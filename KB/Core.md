# Volt KB - Core

This vault is the long-term memory of the Volt project. It grows every session. Nothing here is deleted casually; outdated knowledge is corrected in place or superseded by a linked node.

**Structure: Core -> Path -> Node**

- **Core** (this note) links to every Path.
- **Path** = a folder in `KB/` with an index note of the same name, for example `Mistakes/Mistakes.md`. The index explains what belongs there, gives the node template, and lists the nodes.
- **Node** = one `.md` file about exactly one thing. Never two things in one node. Never one thing spread over two nodes.

## Paths
<!-- kb:auto-start -->
- [[Decisions/Decisions|Decisions]] (7 nodes) - One node per decision Mike has made about Volt, with the alternatives and the conditions for revisiting it. Read in full at every session start.
- [[Library/Library|Library]] (7 nodes) - Long-form source documents kept verbatim for citations and detail, such as research reports and researcher notes. Listed at session start; opened on demand.
- [[Memory/Memory|Memory]] (2 nodes) - One node per session with a compact summary of what was done, why and how. Listed at session start; opened on demand.
- [[Mistakes/Mistakes|Mistakes]] (1 node) - Things that went wrong and the rule that prevents a repeat. Read in full at every session start.
- [[Planning/Planning|Planning]] (2 nodes) - Plans, roadmaps and task breakdowns with their status. Listed at session start; opened on demand.
- [[Research/Research|Research]] (13 nodes) - Reusable knowledge gathered by investigation, documentation reading or web research. Listed at session start; opened on demand.
- [[Standards/Standards|Standards]] (23 nodes) - Conventions and rules for how work on Volt is done. Read in full at every session start.

## Session protocol

1. **Start.** Core, Decisions, Mistakes and Standards are injected into context by the SessionStart hook and count as read. Other Paths (Library, Memory, Planning, Research) are listed by node with a one-line description each; open a node with Read when it is relevant.
2. **During.** When something is learned, record it as a node in the right Path straight away. Do not wait for the end of the session.
3. **End of every working turn.** The Stop hook refuses to end a turn that did work until this session's Memory node exists and is current. Add Decisions, Mistakes, Research or Standards nodes for anything new at the same time.
4. **Git.** The user reviews and commits. Sessions never commit or push.
5. **Address the user as Mike** in every message ([[Standards/address-mike-in-every-message]]).

## Which Path?

| Thing | Path |
| --- | --- |
| Something went wrong and was corrected | Mistakes |
| A convention, rule or way of working (including the code style) | Standards |
| Knowledge gathered by investigation or from the web, distilled | Research |
| A ruling by Mike on what Volt is or how it is built | Decisions |
| A long source document kept verbatim (report, researcher notes) | Library |
| Summary of one session: what, why, how, outcome | Memory |
| Plans, roadmaps, task breakdowns | Planning |

Third-party source snapshots are not nodes; they live in `Reference/` at the repository root and are described by [[Research/reference-source-snapshots]].

## Maintenance

The list under "Paths" and the "Nodes" list in every index note are regenerated by the hooks between the `kb:auto` markers. Text outside the markers is edited by hand. To add a Path, create a folder in `KB/` with an index note of the same name that contains the two markers; the next hook run adds it here.
