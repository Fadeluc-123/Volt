# KB system and enforcement hooks set up
Up: [[Memory]]

**What:**
- Created `KB/Core.md` and index notes with node templates for Memory, Mistakes, Planning, Research and Standards.
- Seeded five Standards nodes with the KB rules; wrote `CLAUDE.md` and `.gitignore`.
- Added `.claude/settings.json` hooks (SessionStart, PreToolUse, PostToolUse, Stop) backed by PowerShell 5.1 scripts in `.claude/hooks/`.
**Why:** The user wants a KB that grows every session and is enforced by code: KB read before work, mistakes and research recorded, git commits left to the user.
**How:** SessionStart injects Core + Mistakes + Standards + Research and sets a per-session marker in `.claude/state/`. PreToolUse denies work tools without the marker (fallback: Read every required file) and denies git commit/push/merge/rebase/cherry-pick/revert and PR creation. PostToolUse tracks KB reads and a "dirty" flag that only writing the session Memory node clears. Stop blocks the turn while dirty, at most two reminders. Index lists between kb:auto markers are regenerated by SessionStart and Stop. Hooks use `powershell.exe` exec form because only Windows PowerShell 5.1 exists on this machine (no pwsh, bash, git, jq, node).
**Outcome:** All scripts pass a synthetic pipe-test suite (gate, git guard, read tracker, dirty flag, Stop retry cap, index regeneration). Hooks went live mid-session: the gate denied this session's first shell calls and opened after the nine required Reads. Index lists verified after regeneration. The SessionStart hook has not yet been observed on a real startup.
