# How Blink 0.18 generates code (and the shape of Blink 1.0 and Zap's emitters)
Up: [[Research]]

**Question:** How does Blink's compiler work, stage by stage, so Volt can borrow or improve on it?

**Answer:** Five stages, all Luau running outside Roblox under Lune (`--!native`, `--!optimize 2`; affects compile speed only):

1. **CLI** (`CLI/init.luau`): parses `blink.exe [CONFIG] [OPTIONS]`; options `--watch`, `--quiet`, `--compact`, `--yes`, hidden `--ast` and `--stats`. Calls `Utility/Compile.luau`.
2. **Compile**: reads the file, parses to an AST, resolves output paths from `ClientOutput` and `ServerOutput`, calls the generator once for "Server" and once for "Client", optionally `GenerateShared` (types file) and `GenerateTypescript` (`.d.ts`), writes the files.
3. **Lexer** (`Lexer.luau`): a table of Lua string patterns tried in order at the cursor. Tokens carry type, value, start, end: `Keyword`, `Primitive`, `Identifier`, `Range` (`(0..8)`), `Array` (`[..10]`), `Optional` (`?`), `Class` (`(Player)`), `Merge` (`..`), `Import`, `As`, punctuation. Whitespace and comments are matched then skipped. Which words are keywords and primitives comes from `Settings.luau`, which also holds each primitive's bounds (`u8` 0..255, `f32` plus or minus 16777216, and so on) and allowed attributes. A `Highlighting` lexer mode keeps whitespace for the Studio plugin editor.
4. **Parser** (`Parser.luau`, about 39 KB): recursive descent with one-token lookahead (`Peek`, `Consume`, `TryConsume`). Options first, then a declaration loop to end of file; keywords route to `Type`, `Struct`, `Enum`, `TagEnum`, `Map`, `Set`, `Tuple`, `Event`, `Function`, `Namespace`, `Import`. Events are parsed by `Structure` against a fixed schema of allowed fields; `From`, `Type`, `Call` must hold permitted words; duplicates and missing fields error with spans. `Data` is a full type expression. Named type references are resolved and **inlined** into the referencing node. Ranges are validated against primitive bounds. Output: a `Body` node holding `Options` and `Declarations`.
5. **Generator** (`Generator/init.luau` about 45 KB, `Prefabs.luau`, `Blocks.luau`, `Util.luau`, `Typescript.luau`; about 80 KB together):
   - **Prefabs**: per-primitive `Read` and `Write` emitters, one line each. `u8` write is `buffer.writeu8(SendBuffer, <offset>, <value>)`; boolean writes `Value and 1 or 0`; Color3 writes three u8; vectors write three components at the chosen encoding; `f16` is hand-rolled bit manipulation. A wrapper adds validation lines: always on the read side, on the write side only when `WriteValidations` is on.
   - **Blocks**: a structured-code builder. `Compare` emits `if`, `Branch` emits `elseif` / `else`, `Loop` emits `for`, `While`, `Iterator`, `End` emits `end`; each returns the nested block so calls chain. **`Allocate(n)` and `Read(n)` do not emit calls; they accumulate a byte count and return the string `BLOCK_START + <offset>`.** On `End` the block inserts `local BLOCK_START = Allocate(<total>)` or `Read(<total>)` at its top: one cursor bump per block, constant offsets per field. Inside an array loop of fixed-size elements it allocates `<element size> * Length` once before the loop. **This is the core of Blink's CPU edge.**
   - **Recursion**: `Generators.UserType` dispatches on node type to `Declarations.Primitive`, `Struct`, `Array`, `Optional`, `Enum`, `TagEnum`, `Map`, `Set`, `Tuple`, passing the same read block and write block. Struct iterates fields with the variable extended to `Value.Field`; Array emits a length prefix sized by the upper bound and opens a loop on both blocks; Optional writes a presence byte and wraps in an `if` (for Instances it checks the side array instead); TagEnum writes a tag byte and branches per variant. **Read and write are built by the same walk, so they cannot disagree.**
   - **Per event**: `Generators.Event` wraps the walk in a function pair in `SerdesFunctions`, writing the event's index byte first. Functions add an invocation ID byte and, on return, a success byte. `Declarations.Event` emits `Fire`, `FireAll`, `FireList`, `FireExcept` on the server (reliable writes go into each player's saved buffer via `Load` and `Save`; unreliable writes are copied and fired immediately) and `Fire` on the client, plus `On` with a disconnect closure, or `Iter` and `Next` for polling. Method names come from the `Casing` option via one lookup table.
   - **Assembly** (`Generator.Generate`) concatenates: directives and version header; the `_G._BLINK` scope guard; the top half of the side template (services); Future or Promise requires; `local SerdesFunctions = {}`; `BASE_EVENT_NAME`; the base runtime; sync-validation locals; queue declarations; Luau `export type` lines; the no-op branch for Studio edit mode; the bottom half of the side template (remotes, `StepReplication`); `RunService.Heartbeat:Connect(StepReplication)` unless `ManualReplication`; the `OnClientEvent` / `OnServerEvent` connections (`while RecieveCursor < Size do` plus the `if` / `elseif` chain); the frozen `Returns` table. Templates are three Luau strings; `Client.luau` and `Server.luau` contain a `-- SPLIT --` marker separating service lookups from remote setup. A release build strips per-field comments.

**Blink 1.0 rewrite pipeline** (from source snapshot): lexer, parser, AST, HIR with analysis passes (dereferencing, flattening, instantiation, type checking), LIR with builders per Luau library (`buffer`, `bit32`, `math`, `string`, `table`, `task`, `vector`, `coroutine`, `debug`, roblox) and per type (`ty/luau/*`, `ty/roblox/*`), an optimizer, then codegen templates (`append_headers`, `append_services`, `append_client`, `append_server`, `append_buffer_fns`). Much larger than 0.18; runs under Lute. Worth reading `compiler/lir/build/builders/ty/` for how each type is lowered and `compiler/codegen/templates/append_server.luau` for the per-player save shape.

**Zap 0.6 output**: emitted from Rust in `zap/src/output/luau/{client,server,mod,types}.rs` with `base.luau` as the runtime template, `typescript/*.rs` for `.d.ts`, `tooling.rs` for the packet-inspector deserializer. Same overall output shape as Blink.
